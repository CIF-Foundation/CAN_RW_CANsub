# CIF CAN RW CANsub

LabVIEW class that reads and writes CAN frames with CCS CANsub devices.

## Installation

1. Install `CIF_Foundation_lib_CIF_CAN_RW_Core` 1.4.0.3 or later.
2. Install the native `cansub_lv_wrapper` library for the target. See [`Installers/readme.md`](../Installers/readme.md).
3. Open **VI Package Manager (VIPM)**.
4. Install `CIF_Foundation_lib_CAN_RW_CANsub` from your VIPM feed or local `.vip` file.
5. Accept the Apache License 2.0 agreement when prompted.
6. Restart LabVIEW if VIPM requests it.

Requires LabVIEW 2021 (64-bit) or later and the CCS CANsub library installed by the native installer.

## Palette Location

After installation, VIs are available on the LabVIEW palette at:

`Functions » Addons » CIF » CAN Read Write » CAN_RW_CANsub`
